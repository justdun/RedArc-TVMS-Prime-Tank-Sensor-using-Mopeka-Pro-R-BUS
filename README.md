# RedArc-TVMS-Prime-Tank-Sensor-using-Mopeka-Pro-R-BUS

This repo enables you to build a module for your RedArc TVMS Prime that will convert the incoming Bluetooth data from up to six Mokepa Pro Universal tank sensors and transmit them over the R-BUS to appear on your RedVision Display and RedVision user application as the TVMS Prime water tank sensors.

This repo contains two Arduino IDE files:

1. The RedArc TVMS Prime Tank Sensor using Mopeka Pro via R-BUS IDE
2. A Mopeka Pro Bluetooth MAC Scanner tool IDE

The main IDE contains instructions on wiring and configuration.

The MAC scanner is required to identify the unique Bluetooth MAC address of each of your Mopeka Pro devices.
